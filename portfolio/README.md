# Developer Portfolio

A modern, responsive personal developer portfolio built with vanilla HTML5, CSS3, and JavaScript (ES6+).

## Features

- ** Dark / Light Theme Toggle** — persisted to `localStorage`
- ** Mobile-First Responsive Layout** — Flexbox + CSS Grid, hamburger menu
- ** Typed Text Animation** — cycling hero subtitle phrases
- **Skills Tab Switcher** — Frontend / Backend / Tools with animated progress bars
- ** Project Filter Grid** — filter by category (Web App / Mobile / API)
- **Project Modal Popups** — full project details, keyboard & click-outside close
- **Contact Form Validation** — client-side validation with live error messages
- ** Scroll Reveal Animations** — powered by IntersectionObserver
- ** Smooth Scrolling Navigation** — with active-link tracking

## Project Structure
